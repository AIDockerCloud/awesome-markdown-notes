## 要点 [事实]

- 项目：https://github.com/hedgedoc/hedgedoc
- 主清单明确写「强项是协作而不是个人知识库」：真源在服务器，多人同编与演示模式是核心场景。
- 前身 CodiMD / HackMD CE，属于社区版自托管路线。

## 归类理由与边界 [推断]

- 本类解决「笔记之间怎么连、怎么查」，而 HedgeDoc 解决的是「多人同时写一篇」；主清单仍把它放在本类，是按自托管 Web 笔记的口径归类，不是按个人知识库。
- 与 [memos](../04-quick-notes/memos.md)、[flatnotes](../04-quick-notes/flatnotes.md) 同为自托管 Web 应用，差别在协作而非速记。
