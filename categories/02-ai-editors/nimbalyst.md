## 一句话定位

不是单纯的编辑器，而是给 coding agent 用的可视化工作台：在同一个窗口里跑 Claude Code、Codex 等 agent，人与 agent 共编 Markdown、图、原型和代码，agent 的改动以红绿 diff 呈现、逐块确认。

## 要点 [事实]

- 入口：https://nimbalyst.com/app/
- 本层的 AI 形态在它这里既不是「内置对话」也不是「社区插件」，而是把 agent 作为共同编辑者接进工作流。
- 主清单同时收录了它自家写的 Typora 替代品测评文（见 [参考资料](../06-references/README.md)），并明确提示「自带自家产品，立场需注意」；引用时应保留这一折扣提示。

## 归类理由与边界 [推断]

- 归本层的依据是「被 agent 读写」这一主清单的核心判断视角，而非编辑手感或排版。
- 数据真源是本地项目 / Git 仓库，与单文件编辑器层一致；差异在协作对象是人 + agent。
