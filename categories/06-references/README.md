> 对应主清单：[根 README.md「已有的同类清单与目录」](../../README.md)

## 本类整体情况

- [事实] 按口径分三组：**Awesome / GitHub 清单 4 个**、**目录站与投票型 3 个**、**测评对比文 2 个**。
- [事实] 只有 Awesome-Selfhosted 与 appsgit 明确了入选门槛（自托管自由软件 / 近半年有提交非 fork）；AlternativeTo 与 Product Hunt 没有编辑口径，属于线索池。
- [事实] 两篇 2026 测评文都含自家产品，主清单已标注立场风险；引用时必须保留折扣提示。
- [事实] 唯一把「数据存哪」写进对比表的是 Markdific，这正是本清单四字段口径关注的维度。
- [未决] 标题带年份的测评文会随时间过期；目录站的收录数量（如 57 款、两百多个）是快照，不宜作为结构性事实引用。

## 每周核实口径

本表不是软件巡检对象，每周核实只做两件事：**链接是否仍可达**、**资源口径 / 立场是否变化**（例如测评文改版、目录站停更）。不判定 Release 与提交活跃度。
