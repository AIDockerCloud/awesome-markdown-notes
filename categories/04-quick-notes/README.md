## 本类整体情况

- [事实] **三款的数据真源互不相同**：SQLite / PostgreSQL + pgvector / 裸 `.md` 文件夹。这是全清单里最适合说明「数据存哪」这一字段的一组对照：
  - flatnotes：正文就是 `.md` 文件，随时可整体搬走换别的软件打开。
  - memos、Blinko：真源是数据库，「Markdown 原生」说的是输入语法，不是存储格式。
- [事实] **部署重量**：memos 最轻（单 Go 二进制或一个 Docker 容器）；Blinko 最重（PostgreSQL + pgvector）；flatnotes 无数据库。
- [事实] **AI 形态**：只有 Blinko 明确写 RAG 自然语言找回，另 2 款未核实；「自托管 + RAG 找回」是它与 memos 拉开差距的两点。
- [事实] flatnotes「明确不设文件夹与笔记本层级」是设计选择，不是功能缺失。
- [未决] 2 款 AI 形态待核实；flatnotes 的链接为 raw 分支 README，需去版本化。
