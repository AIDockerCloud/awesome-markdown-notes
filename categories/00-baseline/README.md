## 本类整体情况

- [事实] 本类只有 1 条，它不是平替候选，而是全清单的判定基准：单文件 + 原地渲染 + 无分栏预览。
- [事实] 四字段全部已判定：闭源、桌面三端、本地 `.md`、无内置 AI。
- [推断] 说「平替」前要先问平的是哪一点 —— 所见即所得手感、免费开源、移动端、AI，还是一整个知识库；答案不同，要看的分区也不同。
- [已确认] 2026-11-10 人类确认口径（原话「typora看官网就可以了」，DEC-007）：闭源且无公开仓库的产品，「近 6 个月内有提交」**以官网发布页 / 更新记录判定**，不以 GitHub 提交判定。Typora 用 https://typora.io/releases/stable.html，DNS 异常时走官方中文站同页。
