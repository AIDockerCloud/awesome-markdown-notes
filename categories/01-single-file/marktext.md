## 一句话定位

与 Typora 手感最接近的开源平替：单窗格实时渲染，底层仍是普通 `.md`。

## 要点 [事实]

- 项目：https://github.com/marktext/marktext
- 单窗格实时渲染，不要求先建库、不要求先同步，符合本层「打开一个 `.md` 就写」的定义。
- 主清单给出的链接是 `develop` 分支下的 README 原文（raw 地址），属于易变目标。

## 归类理由与边界 [推断]

- 本层严格对应 Typora 的手感与单文件工作流，MarkText 是其中手感最接近、且四字段最完整的一条。
- 与知识库层的分界在于「是否先建 vault / 库」；与 AI 编辑器层的分界在于「AI 是内置卖点还是没有」。
