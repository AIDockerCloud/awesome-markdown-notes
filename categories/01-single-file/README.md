## 本类整体情况

- [事实] **数据真源**：9 款中 3 款已判定为本地 `.md`；Aropyt、TypeOpen 与本轮转入的 4 款共 6 款未核实。
- [事实] **AI 形态**：3 款明确无内置 AI，6 款未核实 —— 本层整体不是 AI 卖点，这是与 AI 编辑器层的分界。
- [事实] **协议**：MIT 1、GPL-3.0 2、AGPL-3.0 1、未核实 5；9 款里 4 款明确免费开源。
- [事实] **平台覆盖**：桌面三端 3 款；TypeOpen 仅 macOS；Aropyt 以 Windows 为主、其它平台靠 CI 构建；本轮转入 4 款平台未核实。
- [事实] **手感并不统一**：ghostwriter 是左右分栏预览，与基准的「原地渲染、无分栏」不同。本层按「单文件本地 `.md`」宽口径归类，不是严格按手感对齐，选型时要单独看。
- [已确认] 2026-11-10 人类确认把 Tydora、solomd、morrow、nomo 由候选转入本类正表（DEC-006），四字段待首轮联网核实补齐；其中 morrow 只有测试预览版，是否算「有正式 Release」的入选门槛待复核。
- [已确认] 2026-11-10 人类确认 **TypeOpen 保留在本类正表**，不转候选（DEC-007）；四字段未齐继续显式写「—（未核实）」，不猜测填充。
- [未决] 四字段齐全度 3/9。Aropyt、TypeOpen 与本轮转入 4 款均有字段未判定，是首轮每周核实的优先对象。
- [未决] 3 条链接锚定到 `develop` / `HEAD` 分支或具体 release tag，需去版本化。
